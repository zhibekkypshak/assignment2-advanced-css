# Advanced CSS Assignment

This project is a multi-page website created for Assignment 2 in Web Technologies.

The main purpose of the project is to demonstrate the use of CSS Flexbox and CSS Grid.

## Pages

- Home page with a Flexbox navigation bar
- Cards page with three hobby cards
- Dashboard page created with CSS Grid Areas
- Travel gallery with nine images
- Portfolio page combining Flexbox and CSS Grid

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Project Structure

- `index.html` — home page and navigation bar
- `cards.html` — Flexbox card row
- `layout.html` — dashboard with Grid Areas
- `gallery.html` — image gallery
- `portfolio.html` — personal portfolio
- `style.css` — styles for all pages
- `images` — project images

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
